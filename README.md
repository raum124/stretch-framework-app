# STRETCH Framework App

WebApp für das **STRETCH-Transformations-Framework** (Basis: Whitepaper 1.41).

## Projektziel

Die App macht das STRETCH-Framework digital nutzbar: Teilnehmende geben ihre Situation über ein Eingabetool ein, die App ordnet sie einem der 16 Szenarien des Frameworks zu und erstellt mithilfe einer KI-API eine passende, verständliche Auswertung mit Empfehlungen.

Ein erster Pilot ist mit der Coaching-Akademie Schweiz geplant.

## Geplante Bausteine

- **Frontend**: Eingabe der Daten und Anzeige der Auswertung
- **Backend**: Logik für die 16 Szenarien, Speicherung der Eingaben
- **KI-API**: Generierung der individuellen Auswertung auf Basis des Frameworks
